# ExVectr ground station

Records, visualises and replays data from the ExVectr model Starship and carries the virtual radio. Python core plus browser GUI. See [docs/README.md](docs/README.md) for the index and quick start, and [CLAUDE.md](CLAUDE.md) for the project rules.

```bash
python3 -m venv .venv && .venv/bin/pip install -e '.[dev]'
.venv/bin/exgs core --config config/gs.example.toml
```
