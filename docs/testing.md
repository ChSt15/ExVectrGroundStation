# Testing

Strategy: design section 8.2. The tests need the submodules (`git submodule update --init`): `lib/ExVectrPackets` for the generated packets and vectors, `lib/ExVectrNetwork` for the wire vectors; `tests/vectors.py` loads them. Run everything with `.venv/bin/pytest`; lint with `.venv/bin/ruff check src tests tools` and `ruff format --check src tests tools`.

## Fake source scenarios

`kind = "fake"` options: `echo_rc` (test only, see below), `profile` (`usb` full set, `radio` reduced set with handset `RcState`), `seed`, `speed` (simulated seconds per wall second), `rates` (per-type override, Hz; `0` switches a type off, for example `rates = { FlapState = 0 }` for a vehicle without flap data), `faults`. Fault entries: `{ kind, at, duration, types, scale }` with kinds `dropout` (no packets of `types`), `rate` (scale the rate), `disconnect` (no packets, `LinkStats connected=false`, `GsEvent` down/up), `nan` (one NaN in `Position.pos`), `unknown_enum` (`VehicleState.mode = #9`), `failure_flag` (`fail_sensor` from `at` on). Times are simulation seconds.

`rc_role = "control"` makes the fake source accept GS `RcState` through `send()` (what a control link does); it keeps the last ones in `received_rc` for tests. **`echo_rc = true`** (test only, design 6.5): the last received value of `echo_channel` (1-based, default 5, the SA channel of the Pocket config) is echoed as `MissionState.mission_index` = `round((us - 1000) / 500)`, so `exgs wait 'MissionState.mission_index == 2'` closes the radio loop. It implements no vehicle logic; a real vehicle never does this.
