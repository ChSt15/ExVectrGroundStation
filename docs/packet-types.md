# Packet types

Generated by `exgs schema --markdown` from the packet registry. Do not edit by hand.
A test fails if this file is out of date.

All fields are optional (`None` = not supplied by this link) and omitted from log lines then.
Every packet also carries `t` (host receive time, ns since Unix epoch) and `src` (source id).

## Attitude

## Gps

GNSS solution, lat/lon in radians. USB GNSS (0x83) fills every field; the radio's AIR_GNSS (10 Hz: position and velocity) and AIR_GNSS_INFO (1 Hz: fix type, satellites, accuracy) are merged by the wire profile into one Gps per source, the info fields carried until the next AIR_GNSS_INFO. Unknown values (wire sentinels) are None.

Version 1, direction `down`, nominal rate 10 Hz, history: yes.

| Field | Kind | Unit | Description |
|---|---|---|---|
| `lat` | float | rad | None = no fix |
| `lon` | float | rad | None = no fix |
| `alt` | float | m | receiver altitude (u-blox: height above the WGS-84 ellipsoid), None = unknown |
| `vel` | float_array[3] | m/s | NWU, None = unknown Elements: x, y, z. |
| `num_sats` | int | - |  |
| `fix_type` | int | - | GNSS fix type as reported (exvectrnet-1 profile only) |
| `pos_acc` | float | m | horizontal accuracy, None = unknown |
| `alt_acc` | float | m | vertical accuracy, None = unknown |
| `vel_acc` | float | m/s | speed accuracy (USB GNSS only) |
| `info_t` | time_ns | ns | host time of the AIR_GNSS_INFO the info fields come from (radio path only) |

## Calibration

CALIBRATION (USB only, every 2 s): the sensor calibration the vehicle applies. For each sensor cal = M * (raw - offset), M row-major (M[r][c] = matrix[3r + c]), raw = ImuRaw in raw_frame; SI. The ground station only displays the result.

Version 1, direction `down`, nominal rate 0.5 Hz, history: no.

| Field | Kind | Unit | Description |
|---|---|---|---|
| `raw_frame` | int | - | frame of the ImuRaw values the parameters apply to (0 = SENSOR, driver output) |
| `gyro_source` | int | - | bits: 0 calib EEPROM, 1 transform EEPROM, 2 offset override, 3 RAM only, 4 memory cleared |
| `accel_source` | int | - | as gyro_source |
| `mag_source` | int | - | as gyro_source |
| `gyro_offset` | float_array[3] | rad/s | Elements: x, y, z. |
| `gyro_matrix` | float_array[9] | - | row-major 3x3, scale and misalignment times sensor to body |
| `accel_offset` | float_array[3] | m/s^2 | Elements: x, y, z. |
| `accel_matrix` | float_array[9] | - | row-major 3x3 |
| `mag_offset` | float_array[3] | T | Elements: x, y, z. |
| `mag_matrix` | float_array[9] | - | row-major 3x3, dimensionless |
| `gyro_bias_est` | float_array[3] | rad/s | EKF gyro bias, body frame Elements: x, y, z. |

## LegacyRow

One row of an old ExVectrController CSV log, columns as logged (names and units of the old logger, no frame or unit conversion), written by `exgs log import-legacy` next to the converted packets so nothing is lost (docs/legacy-logs.md). A field is None when the file's layout has no value for that column.

Version 1, direction `local`, nominal rate 10 Hz, history: no.
